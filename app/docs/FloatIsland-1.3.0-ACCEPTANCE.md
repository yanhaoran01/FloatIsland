## 实测发现与修复

- 右侧 150% 缩放时 DIP 取整产生物理间隙：改为 Win32 实际工作区校准，保持渲染尺寸，原生复测通过。
- 贴图 closed 回调读取已销毁 BrowserWindow 导致未捕获异常和模态阻塞：缓存 webContents 身份，关闭后再次录制／取消通过。
- 窗口截图隔离到受限 GDI 工作线程，避免全窗口缩略图采集干扰；只操作获选窗口句柄并设超时。
- 打包的原生 GUI 校验原先把脚本作为应用参数而未执行：改为受控 Node 编排器实际附加打包进程 inspector，不增加应用生产测试接口。
- 生产显式固定 koffi 2.16.2，避免 transitive/native bundling 缺失；打包验证拒绝旧 out。
- 录屏宿主启动超时、owner 清理和任务 destroyed 监听收尾；取消和应用退出释放资源。录屏使用麦克风时角色静音。
- LocalSend 发送 TLS 连接按协议 fingerprint 检查目标身份，未验证身份不能上传文件正文。
- 生成产物重命名撤销恢复原显示名；真实流程复测通过。
- 长截图普通较大滚动被匹配范围错误拒绝；扩大重叠搜索并验证原生拼接和底部像素。
